GOOGLE SHEETS CLOUD SETTINGS

วาง Web App URL ที่ได้จากการ Deploy Google Apps Script ใน Google Drive

วิธีสร้างและเชื่อมต่อ Google Sheets:

  1. เปิด Google Sheets ใหม่ใน Google Drive
  2. เลือกเมนู ส่วนขยาย (Extensions) > Apps Script
  3. วางโค้ด Apps Script (ที่ระบบเตรียมไว้ให้)
  4. กด การทบทวน/Deploy > เลือก เว็บแอป (Web App)
  5. ตั้งค่า ผู้มีสิทธิ์เข้าถึง (Who has access) เป็น "ทุกคน (Anyone)"
  6. คัดลอก URL มาวางในช่องด้านบนแล้วกด บันทึก
